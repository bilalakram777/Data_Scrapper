Book Price Scraper (Python)
This Python script scrapes book titles and prices from the website Books to Scrape using requests and BeautifulSoup. It performs the following steps:

Fetches the HTML content of the target webpage

Parses and extracts book titles and prices

Saves the extracted data into a CSV file (scraped_books.csv)

The script demonstrates basic web scraping and CSV handling, making it a good starting point for beginners interested in data extraction from websites.
